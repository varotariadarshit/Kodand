AI assistant settings

Configure the provider used by the "AI Review" button on findings in a report. API keys are stored locally in the Kodand workspace, never sent anywhere except the provider you configure.

MCP Server

Lets MCP-capable agents (Claude Code, Cursor, etc.) call Kodand directly as a tool during a session — run scans, verify findings, browse scanned files. Connects over stdio: the agent launches kodand mcp itself; nothing is exposed on the network.

Claude Agent

Verifies findings with your own Claude Code and Claude login — no API key. Run kodand agent in a terminal and leave it open: it picks up the findings you send from a report or a new scan one at a time, runs Claude Code on each, and adds the verdict as a comment. Nothing runs while no finding is waiting. It can only use Kodand's own tools, and only on projects shared with MCP agents above; review statuses stay yours to set.

About Kodand console (v3)

Same engine as the Kodand CLI. v3 adds literal+regex matching, encoding normalization, Context Engine v2, finding dedup, proximity/multi-signal escalation, composite 0–100 confidence scoring, and a suppression framework. Projects store scans + reports under the workspace folder below.
