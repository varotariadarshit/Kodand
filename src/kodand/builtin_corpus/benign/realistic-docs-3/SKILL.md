You can download the latest release from our GitHub page and install it locally.
Configure your project by setting the DATABASE_URL environment variable in the shell.
Set sort_key: name in the config file to change ordering.
Run chmod 644 on the config file so only the owner can write to it.
The chart sets privileged: false by default for all workloads.
We recommend keeping dependencies up to date; run pip install --upgrade regularly.
